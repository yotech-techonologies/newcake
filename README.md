# Sweet Layers – simple cake ordering site

A static site (HTML, CSS, JS). No build step, no backend.
Customers pick cakes, fill in a form, and the order opens as a WhatsApp message to you.

## Customize
Open `script.js` and edit `WHATSAPP_NUMBER`, `CURRENCY` and the `CAKES` list.

## Publish on GitHub Pages
1. Create a new repository and upload these files to the root.
2. Go to Settings > Pages.
3. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. Your site goes live at `https://<your-username>.github.io/<repo-name>/`.
